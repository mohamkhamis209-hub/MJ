# دليل الصياغة البرمجية للغة إم جي (MJ Syntax Reference)
**المبتكر:** محمد خميس  
**الشعار:** "فكر بما وراء الصيغة البرمجية."

---

## 1. الإعلان عن المتغيرات والثوابت
- **متغير (Mutable Variable):**
  \`\`\`mj
  متغير العداد = 0
  العداد = العداد + 1
  \`\`\`
- **ثابت (Immutable Constant):**
  \`\`\`mj
  ثابت النسبة_التقريبية = 3.14159
  // محاولة تغيير الثابت ستنتج خطأ دلالياً واضحاً
  \`\`\`

## 2. الشروط والتفرع (إذا / وإلا)
تدعم إم جي الصيغتين: ذات الأقواس وذات النقطتين:
\`\`\`mj
إذا س > 10:
    اطبع("أكبر من عشرة")
وإلا:
    اطبع("أصغر من أو يساوي عشرة")
\`\`\`

## 3. الحلقات التكرارية
- **حلقة طالما (While):**
  \`\`\`mj
  متغير ع = 1
  طالما ع <= 5:
      اطبع(ع)
      ع = ع + 1
  \`\`\`
- **حلقة لكل (For-In):**
  \`\`\`mj
  لكل عنصر في [10، 20، 30]:
      اطبع(عنصر)
  \`\`\`
- **حلقة كرر (Repeat):**
  \`\`\`mj
  كرر (3):
      اطبع("تنفيذ إم جي")
  \`\`\`

## 4. تعريف الدوال
\`\`\`mj
دالة مربع(س):
    أرجع س * س

اطبع(مربع(10)) // النتيجة: 100
\`\`\`
